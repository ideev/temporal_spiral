# Temporal Spiral

Интерактивный эскиз фотоархива: спираль времени → год → событие → фотографии.

## Запуск

Нужен Python 3. Из каталога репозитория:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Приложение доступно на порту 3000. Сборка и установка npm-пакетов не нужны. Также можно использовать `npm start` при наличии Node.js.

Выберите точку спирали или год на нижней шкале, затем карточку события. В просмотрщике работают стрелки клавиатуры и Escape. «Общий вид» сбрасывает приближение и возвращает 1969 год. Поддерживается системная настройка уменьшения анимации.

Это статический прототип без сервера данных, загрузки пользовательских фотографий и сохранения. Основные снимки NASA сохранены в `assets/`; фотографии Берлинской стены, «Уэбба» и шрифты загружаются из внешних источников; при недоступности снимка остаются описание и ссылка на оригинал. Источники и авторство указаны в просмотрщике. Данные демонстрационных подборок находятся в `app.js`; некоторые исторические фотографии сделаны позже даты начала события (дата снимка указана в подписи).
